# EduTrack

Plataforma de gestión académica en español, pensada para administradores, docentes, estudiantes y acudientes.

> Este repositorio contiene la documentación del proyecto. El código de la aplicación no se publica aquí.

## Características

**Gestión académica**
- Calificaciones
- Asistencia
- Horarios

**Suite de productividad**
- Gestor de tareas
- Calendario
- Seguimiento de hábitos
- Metas
- Temporizador Pomodoro
- Perfiles de usuario

**Seguridad y roles**
- Autenticación con sesiones seguras
- Control de acceso basado en roles (RBAC) con cuatro paneles: administrador, docente, estudiante y acudiente
- Gestión de usuarios (CRUD)

## Tecnologías

| Capa | Tecnología |
|------|-----------|
| Backend | PHP |
| Base de datos | MySQL |
| Frontend | HTML y CSS |
| Entorno local | XAMPP |
